# Pet Images Directory

Add your breed-specific pet images here:

## Required Images:

### Puppies:
- `oes-puppy.jpg` - Old English Sheepdog puppy
- `german-shepherd-puppy.jpg` - German Shepherd puppy  
- `doberman-puppy.jpg` - Doberman puppy

### Kittens:
- `sphynx-kitten.jpg` - Sphynx kitten
- `maine-coon-kitten.jpg` - Maine Coon kitten
- `siamese-kitten.jpg` - Siamese kitten

## Image Requirements:
- Size: 400x400 pixels (square)
- Format: JPG, PNG, or WebP
- Recommended: Face-focused, well-lit, clear images

## Sources:
You can find free images on:
- Unsplash.com - Search for specific breeds
- Pexels.com - Free stock photos
- Pixabay.com - Free images

Once you add the images with the exact filenames above, they will automatically display in the app!
